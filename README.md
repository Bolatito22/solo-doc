# solo-doc

## Getting Started with VS Code and Github
This guide will help you set up the basic tools you need to create, manage,
collaborate on, and publish documentation. Prior coding experience is not needed for this, because the goal is not about memorizing steps but to understand the basic workflow.

## 1. How to Install VS Code

Visual Studio Code [VS Code](https://code.visualstudio.com/) is a text editor that makes it easier to work with Markdown, HTML, and other plain-text files. 
If you are working on [ISU](https://www.iastate.edu/) laptop, you might need to down VS Code from self service. Otherwise, you can download VS Code using the above link.

After installing VS Code, open the **Extensions** panel and install an extension
such as **Markdown All in One**. Extensions add features to VS Code without
requiring you to install a different program.
See [VS Code's extension documentation](https://code.visualstudio.com/docs/configure/extensions/extensionmarketplace) if you need help.
